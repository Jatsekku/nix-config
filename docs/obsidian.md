
## Plugins

### supernote-obsidian-plugin
[![supernote-obsidian-plugin](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github)](https://github.com/philips/supernote-obsidian-plugin)

Supernote Obsidian Plugins is Supernote integration for Obsidian. \
It allows you:
 - Include Supernote's notes into Obsidian's markdown notes.
 - Export Supernotes's notes as PNGs/markdown.
 - Copy an image from Supernote via screen mirroring into Obsidian note.
 - Downloading/Uploading files directly from Supernote devices.
